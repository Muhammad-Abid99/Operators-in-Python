
# Operators in Python

This repository contains a Jupyter Notebook that demonstrates different types of **operators in Python** using simple examples. It is designed for beginners who want to understand how operators work in Python.

## 📘 Topics Covered

The notebook includes the following operator types:

1. **Arithmetic Operators**
   Basic math operations like addition (`+`), subtraction (`-`), multiplication (`*`), division (`/`), modulus (`%`), exponentiation (`**`), and floor division (`//`).

2. **Assignment Operators**
   Assign values to variables using `=`, and combine assignment with arithmetic using `+=`, `-=`, `*=`, `/=`, `%=`, `//=`, and `**=`.

3. **Comparison (Relational) Operators**
   Compare values using `==`, `!=`, `>`, `<`, `>=`, and `<=`.

4. **Logical Operators**
   Combine multiple conditions using `and`, `or`, and `not`.

## 🚀 How to Run

To run this notebook on your local machine:

1. Clone this repository:

   ```bash
   git clone https://github.com/Muhammad-Abid99/Operators-in-Python.git
   cd Operators-in-Python
   ```

2. Install Jupyter Notebook (if not already installed):

   ```bash
   pip install notebook
   ```

3. Launch the notebook:

   ```bash
   jupyter notebook
   ```

4. Open `Operators_in_Python.ipynb` and follow along.
